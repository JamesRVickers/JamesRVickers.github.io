Projects

-rwxr-xr-x cluedo-game/ Java

A console implementation of Cluedo, built from the ground up — board and estate modelling, card system (estate / weapon / player cards), and guess logic.

  • Designed an ASCII console UI: map panel, player/estate/weapon info panel, card display, and a command input area (see / move / guess)
  • Step-by-step movement — WASD per move, dice roll of 1–6, with a per-turn trail that blocks backtracking onto tiles already stepped on that turn
-rwxr-xr-x tower-defense/ Unity · C#

A 2D tower defense game built in Unity, focused on getting the underlying combat systems solid before layering on content.

  • Debuff and speed-recalculation architecture for enemy units
  • Coroutine-based tower attack cooldowns, with targeting logic and projectile gizmo rendering
  • Fixed a URP sprite-sorting issue (Y-axis depth ordering) via the Renderer2D Data asset's Transparency Sort settings
